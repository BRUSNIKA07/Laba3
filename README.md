# Fortuna — казино на Django

Рулетка и слоты на жетонах. Django + SQLite, страницы на шаблонах, оформление и анимация на CSS/JS.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate          # macOS / Linux: source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Открыть http://127.0.0.1:8000/ — тесты: `python manage.py test`.

## Как это устроено (MVC в терминах Django)

| MVC | В Django | Где лежит |
|---|---|---|
| Model | Model | `casino/models.py` (игрок, журнал раундов), правила игр — `casino/games.py` |
| View | Template | `casino/templates/casino/*.html`, стили и скрипты — `casino/static/casino/` |
| Controller | View | `casino/views.py`, маршруты — `casino/urls.py` |

Результат каждой игры выбирает сервер, а не браузер. Баланс списывается и начисляется атомарно в SQLite.

## Правила

- Старт: 10 жетонов, ставка в каждой игре от 1 до 5.
- Рулетка: 37 секторов (0 и 36 чисел), четыре ставки — красное чётное, красное нечётное, чёрное чётное, чёрное нечётное. У каждой 9 чисел из 37, выплата ×4. Зеро забирает ставку.
- Слоты: сетка 3×3, выигрыш считается только по центральной линии — позиции (1,2), (2,2), (3,2) в виде (колонка, ряд). Три одинаковых символа умножают ставку по таблице.

- Наперстки: 3 стакана, шарик под одним: его сначала показывают, потом стаканы тасуют вместе с шариком, нужно выбрать тот же стакан. Стакан с шариком выбирает сервер и сам проверяет ответ (ответ раньше, чем кончилось перемешивание, отклоняется). Угадал — ставка ×2, дальше «супер игра»: каждая следующая победа подряд даёт ×3, ×4… Промах сжигает ставку, выигрыш можно «Забрать» в любой момент. Ставка списывается при старте, выплата — при «Забрать». Партия хранится в сессии.
- Слоты рисуются SVG-оберегами (Засеянное поле, Громовик, Лунница, Жар-птица, Алатырь), рисунки — `templates/casino/_sprite.html`, id `sym-<ключ>`.

Менять правила: `casino/games.py` (`SLOT_PAYTABLE`, `THIMBLES_CUPS`, `WIN_LINE`, `ROULETTE_MULTIPLIER`, `MIN_BET`, `MAX_BET`).

## Тема

Славянский стиль: тёмное дерево, красная вышивка, латунь (орнаменты — переменные `--orn*` в начале `style.css`). Тёмная по умолчанию. Кнопка в шапке переключает тему, выбор хранится в `localStorage`. Цвета обеих тем — переменные в начале `style.css`. Светлая тема пока заготовка.

## Если жетоны закончились

Для заработка есть мини игры(змейка, флеппи берд, сапер), секретный код на 99999 жетонов, или поправьте баланс в админке — `python manage.py createsuperuser`, затем `/admin/`.

## Дальше: аккаунты

В Django уже есть `django.contrib.auth`: имя пользователя и пароль хранятся в SQLite, пароль — в виде хеша, а не открытым текстом. Достаточно добавить в `Player` поле `user = OneToOneField(User, null=True)` и страницы входа и регистрации. Кнопки в меню аккаунта теперь влючены.
требования для пароля: минимум одна цифра, минимум одна заглавная, минимум 8 символов, пример Fortuna1
