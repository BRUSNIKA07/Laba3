О проекте

Fortuna — веб-приложение на Django с тремя играми на жетонах, мини-играми для разнообразия и системой пополнения баланса. Результат каждой игры выбирает сервер, а не браузер: клиент только рисует анимацию. Баланс списывается и начисляется атомарно, а все важные проверки (ставки, время партии, доступ к мини-играм, сумма пополнения) делаются на сервере.

Важно. Это учебная работа. Жетоны нужны только для игры и не выводятся в деньги. Онлайн-казино с реальными деньгами в России запрещены, поэтому проект не предназначен для публикации в интернете.

Возможности
	
🎡 Рулетка	37 секторов, четыре комбинации (цвет × чётность), выплата ×4
🎰 Слоты	Сетка 3×3, выигрыш по центральной линии, символы-обереги в SVG
🥤 Напёрстки	Угадай стакан с шариком, серия побед с растущим множителем
🕹️ Мини-игры	Змейка, Жар-птица, Сапёр: жетоны за рекорды (открываются после первого пополнения)
💳 Пополнение	Ввод суммы, живой пересчёт в жетоны, оплата по QR, подтверждение в админке
🎟️ Промокоды	Бонус к жетонам при пополнении, действует на каждый заказ
👤 Аккаунты	Регистрация и вход, пароли хранятся хешами, баланс сохраняется
🌗 Тема	Тёмная и светлая, выбор запоминается в браузере
Быстрый старт

Нужен Python 3.12 или новее.

Windows (PowerShell)

powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

macOS / Linux

bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

Правила игр

Ставка в каждой игре — от 1 до 5 жетонов. Новый игрок начинает с 0 жетонов.

Рулетка

37 секторов (0 и числа 1–36). Четыре ставки: красное чётное, красное нечётное, чёрное чётное, чёрное нечётное. У каждой по 9 чисел из 37, выплата ×4. Зеро забирает ставку.

Слоты

Сетка 3×3, считается только центральная линия. Три одинаковых символа умножают ставку:

Символ	Вес выпадения	Множитель
Засеянное поле	10	×5
Громовик	6	×14
Лунница	4	×35
Жар-птица	2	×120
Алатырь	1	×400
Напёрстки

Три стакана. Сначала показывают, под каким шарик, затем стаканы перемешивают. Нужно выбрать тот же стакан.

Угадал: ставка ×2, дальше «супер игра», каждая следующая победа подряд поднимает множитель (×3, ×4…).
Промах сжигает ставку.
Выигрыш можно забрать в любой момент.
Ставка списывается при старте, выплата приходит при «Забрать». Ответ раньше окончания перемешивания сервер отклоняет.
Мини-игры

Открываются после первого подтверждённого пополнения. Награда не больше 10 жетонов за партию, время партии сервер берёт из своей отметки.

Игра	Награда
Змейка	1 жетон за 3 яблока
Жар-птица	1 жетон за 3 трубы
Сапёр	8 жетонов за победу
Пополнение баланса

Курс: 5 ₽ = 1 жетон, сумма от 5 до 5000 ₽ (целые рубли).

Игрок вводит сумму → видит жетоны → «Создать заказ» → платит по QR
   → пишет код заказа в комментарии → «Я оплатил»
        → админ видит деньги в банке → «Подтвердить оплату» → жетоны на балансе
На /topup/ игрок вводит сумму (и промокод, если есть). Страница сразу показывает, сколько жетонов он получит.
Создаётся заказ с кодом вида A1B2C3. Игрок переводит сумму по QR и пишет код в комментарии.
Жетоны начисляет только администратор: /admin/ → Payments → отметить заказ → действие «Подтвердить оплату (начислить жетоны)». Повторное подтверждение ничего не начисляет.
Итоговое число жетонов считает сервер, подменить его через браузер нельзя. Пополнять могут только вошедшие в аккаунт, и не больше 5 неоплаченных заказов одновременно.

Свой QR. Положите картинку в casino/static/casino/img/pay-qr.jpg и обновите страницу. Пока файла нет, на странице заказа показывается подсказка.

Промокоды. Список задан словарём PROMO_CODES в casino/payments.py (код в нижнем регистре → бонус в процентах). Регистр и лишние пробелы при вводе не важны.

Безопасность
Исход игр выбирает сервер (random.SystemRandom), результат нельзя предсказать.
Баланс меняется одной атомарной операцией, уйти в минус или потратить жетоны дважды нельзя.
Мини-игры закрыты и на странице, и на уровне запросов, пока нет подтверждённого пополнения.
Награды за мини-игры проверяются по времени партии, которое засекает сервер.
Пароли хранятся только в виде хешей; правила: от 8 символов, латиница, цифра и заглавная буква.
Для публикации замените SECRET_KEY, отключите DEBUG и задайте ALLOWED_HOSTS в config/settings.py.
